How to play

You run one website through four eras of the internet. Each era looks, talks and pays like its year.

  • Site. This is what visitors see. Press the promote button to bring in traffic by hand.
  • View source. This is the back end. Fill the blank in each line of code to add a feature. Every feature brings more traffic on its own.
  • Messenger. Friends, sponsors and buyers write to you. Your answers change the story.
  • Time machine. Finish an era to unlock the next year. Every year keeps running while you are away, and you can go back.

Going back is worth it. You will know things in 1996 that nobody else does.

Where this came from

Matt wanted a game about the internet itself: the homepages, the Flash portals, the feeds and the bots, all running at once. The code in it is real syntax from each era, and every company in it is made up.

Your game saves in this browser by itself.
